# Pixel Beacon: take it home

The phone page for [Pixel Beacon](https://github.com/alsafranhh-art/pixel-beacon), a booth activity where kids draw pixel art and "beam" it like the 1974 Arecibo message.

The QR code next to a poster opens this page with the whole drawing packed into the link (after the `#`). The page rebuilds it in the browser and offers two downloads:

- **Picture:** the poster as a PNG.
- **Sound:** the alien radio signal as a WAV (1320 Hz for a 1, 880 Hz for a 0).

Nothing is uploaded. The drawing never leaves the phone, and there is no server.
